الجزء 1: ملخص المحاضرة الرابعة: كتابة الكود وتنفيذه والبرمجة بمساعدة الذكاء الاصطناعي

Pseudocode, Python Translation, CPU Execution, and AI-Assisted Coding

ملخص سريع (Summary)

  • الـ Pseudocode (الكود الصوري) هو خطوة وسيطة بتشرح منطق الحل بلغة بسيطة قبل كتابة الكود الحقيقي.
  • تحويل الـ Pseudocode لـ Python بيحتاج تطبيق قواعد اللغة (Syntax) زي الإزاحة (Indentation) والـ Variables.
  • اختبار الكود (Testing) وتصحيحه (Debugging) بيحتاج نختبر الحالات العادية وحالات الحدود (Boundary Values) والقيم غير الصالحة (Invalid Inputs).
  • الكود بيتحمل من الـ SSD للـ RAM، والـ CPU بيكرر دورة التعليمات: جلب (Fetch)، فك التشفير (Decode)، وتنفيذ (Execute).
  • الـ Vibe Coding بيعتمد على التفاعل السريع مع الذكاء الاصطناعي وتوليد الكود التجريبي دون التعمق في تفاصيله.
  • الـ Agentic Engineering هو الانضباط الهندسي اللي بيضمن المراجعة البشرية (Human Review) واختبار الحدود لضمان جودة الكود وصحته.

الشرح (Explanation)

التحويل من الـ Pseudocode إلى Python (Translating Pseudocode to Python)

الـ Pseudocode هو التعبير عن الخوارزمية بلغة منظمة ومستقلة عن أي لغة برمجة. بيستخدم كلمات مفتاحية واضحة زي READ و SET و WHILE و PRINT. الإزاحة (Indentation) في الـ Pseudocode مهمة جداً لأنها بتحدد أجزاء الكود التابعة للحلقات التكرارية (Loops) أو الشروط. لما بنحوله لـ Python، بنترجم نفس المنطق لقواعد اللغة (Syntax). مثال Python من المحاضرة لحساب مجموع الأرقام من 1 إلى N: ```python n = int(input("N: ")) i = 1 total = 0 while i <= n: total = total + i i = i + 1 print(total) ``` المتغير (Variable) زي total بيتخزن فيه الناتج، والـ while loop بتكرر بدقة طالما الشرط متحقق. المنطق ثابث لكن الملاحظة البرمجية فقط هي اللي بتتغير.

Pseudocode = كود صوريIndentation = الإزاحة المحددة للهيكلSyntax = قواعد لغة البرمجة

اختبار الكود وتصحيح الأخطاء (Testing and Debugging)

عشان نتأكد إن البرنامج شغال صح، مش كفاية نختبر حالة واحدة بنجاح. الاختبار السليم بيشمل: الحالات العادية (Normal Inputs)، وحالات الحدود (Boundary Values)، والمدخلات غير الصالحة (Invalid Inputs). الأخطاء المنطقية (Logic Errors) بتظهر في حالات الحدود؛ مثلاً لو المطلوب إن درجة 50 تكون نجاح، وكتبنا في الكود `if score > 50` بدلاً من `score >= 50`، الطالب اللي جايب 50 هيسقط وده خطأ منطقي. بنكتشف الأخطاء دي باستخدام جدول التتبع (Trace Table) اللي بيسجل قيم المتغيرات بعد كل خطوة، وبنختبر القيم على الحافة زي 49 و 50 و 100، بالإضافة للقيم السالبة لمنع أي سلوك غير متوقع للبرنامج.

Boundary Values = قيم الحدودLogic Error = خطأ منطقيTrace Table = جدول تتبع المتغيرات

كيف يصل الكود للـ CPU وتتم دورة التنفيذ (Fetch-Decode-Execute)

الـ CPU مبيشغلش الكود مباشرة من الـ SSD لأن الـ SSD تخزين دائم وبطيء نسبياً. عند تشغيل البرنامج، بيتم تحميل التعليمات والبيانات الأولية إلى الـ RAM (ذاكرة الوصول العشوائي). بعد كده، الـ CPU بيبدأ يكرر دورة التعليمات (Instruction Cycle) مليارات المرات في الثانية عبر 3 مراحل الأساسية: 1. الجلب (Fetch): قراءة التعليمة القادمة من الـ RAM باستخدام عنوانها في مسجل الـ Program Counter (PC) ووضعها في الـ Instruction Register (IR). 2. فك التشفير (Decode): تحليل التعليمة بوساطة وحدة التحكم (Control Unit) لمعرفة العملية المطلوبة. 3. التنفيذ (Execute): إجراء العملية داخل الـ ALU أو المسجلات (Registers) وتحديث النتيجة. كما تُستخدم الـ Data Cache لتخزين البيانات المتكررة لتسريع الوصول إليها دون الرجوع للـ RAM دائماً.

Instruction Cycle = دورة تنفيذ التعليمةProgram Counter (PC) = عداد البرنامجInstruction Register (IR) = مسجل التعليمة الحالية

الذكاء الاصطناعي في البرمجة: من الـ Vibe Coding إلى الـ Agentic Engineering

تطورت أدوات الذكاء الاصطناعي في البرمجة بشكل كبير. مصطلح Vibe Coding (اللي أطلقه Andrej Karpathy سنة 2025) بيوصف العمل التفاعلي السريع؛ حيث بتكتب وصف باللغة الطبيعية وتولد كود وتجربه فوراً بدون مراجعة تفصيلية لأسطر الكود. لكن الأسلوب ده ممكن يخفي أخطاء منطقية. في المقابل، الـ Agentic Coding بيعطي أدوات AI القدرة على اتخاذ خطوات متتابعة، قراءة وتعديل الملفات، وتشغيل الاختبارات تلقائياً. وهنا بييجي دور الـ Agentic Engineering وهو الانضباط الهندسي اللي بيتطلب خبرة المبرمج البشري في تحديد المتطلبات، ومراجعة تعديلات الكود (Code Review)، واختبار شروط الحدود والأمان، واتخاذ قرار الاعتماد والتسليم النهائيات.

Vibe Coding = البرمجة التفاعلية السريعة بالإنطباعAgentic Coding = البرمجة الذاتية التفاعلية عبر الأدواتAgentic Engineering = الهندسة البرمجية الموجهة للوكلاء
